HOTEL PRO SYSTEM - Sistema Profissional de Hotel

COMO RODAR:
1. Abra o terminal dentro da pasta hotel_pro_system
2. Instale as dependências:
   pip install -r requirements.txt
3. Rode o sistema:
   python app.py
4. Abra no navegador:
   http://127.0.0.1:5000

LOGIN PADRÃO:
Usuário: admin
Senha: admin123

RECURSOS INCLUÍDOS:
- Login e permissões por tipo de usuário
- Dashboard profissional
- Cadastro de hóspedes
- Cadastro de quartos
- Reservas com controle de disponibilidade
- Check-in e check-out
- Financeiro com pagamentos
- Frigobar e consumos por quarto
- Limpeza/Governança
- Manutenção
- Funcionários
- Empresas e agências
- Auditoria de ações
- Backup do banco
- Importação Excel
- Exportação Excel
- Exportação PDF
- Tema claro/escuro
- Busca e filtros

OBS:
Este é um sistema completo inicial, pronto para evoluir para produção.
Para usar em hotel real, recomendo trocar SQLite por PostgreSQL e hospedar em servidor.
